# website

The source of [toon.ar.io](https://toon.ar.io): the TOON Protocol landing page, the docs
and the ecosystem page.

```
index.html              the landing page: hand-written; build.py copies the stylesheet into it
docs/*.html             built from src/docs/*.html by build.py
ecosystem/index.html    built from src/ecosystem.html by build.py
assets/site.css         the one stylesheet, shared by every page
assets/fonts/           Archivo 800 and JetBrains Mono, self-hosted, latin subsets
assets/icon/            the mark, as SVG and PNG
build.py                the only build step; standard library only
manifest.template.json  the Arweave path manifest, regenerated by build.py
src/                    the page fragments you edit
```

The only script on the site is the copy button on the landing page. The site is stored on Arweave and reached through the ArNS name
`toon`. Each revision of the landing page is bought as a paid TOON write through the live
node, and the docs page "Proof" (`src/docs/proof.html`) embeds the receipts of the revisions
before it.

## Editing

- **The landing page** is `index.html`. Edit its markup directly. Its `<style>` block is a
  copy of `assets/site.css` that `build.py` refreshes on every build, so the one file stands
  alone, as every earlier revision did, while the stylesheet has a single source. Edit
  `assets/site.css`, never the copy.
- **The look** follows the mark in `assets/icon/`: cream, charcoal, gold and grey, with a
  dark scheme for `prefers-color-scheme: dark`. Display type is Archivo 800, labels and code
  are JetBrains Mono, both served from `assets/fonts/`; nothing is loaded from another host.
- **A docs page** is a body fragment in `src/docs/<slug>.html`. The title, summary, section
  and order come from `NAV` in `build.py`. Every `<h2>` gets an anchor and an entry in the
  page's table of contents. End each page with a `<p class="source">` naming the
  repository file it was written from, so the next editor can check it against the source.
- **The ecosystem page** is `src/ecosystem.html`.
- Then run the build:

  ```sh
  python3 build.py
  ```

Preview with any static server, for example `python3 -m http.server 8765`, then open
`http://127.0.0.1:8765/`.

## Before publishing

1. **Prices.** The "Priced live" tiles and the endpoints table on the ecosystem page are a
   snapshot read off the live node's `GET /ilp`. Reread it and update the dates if a price
   changed.
2. **Release tags.** The version named in `src/docs/install.html` is toon_cli's latest
   release (`gh release list -R toon-protocol/toon_cli`); the Docker tag in
   `src/docs/run-a-node.html` is the connector's (`gh release list -R toon-protocol/connector`).
3. **Docs drift.** Each docs page names the repository file it was written from. Diff that
   file against the last time the page was touched.
4. **Receipts.** Add the landing-page revision being replaced to the list in
   `src/docs/proof.html` and to the JSON in its `<details>` block: its Arweave transaction id (the `x-arns-resolved-id`
   header of `curl -sI https://toon.ar.io`), `sha256sum` of the file as served, byte size,
   the claim on each hop, and the block date. A page cannot contain its own hash, so this
   is always done for the previous revision, never the current one.
5. **Links.** Every link must resolve. Internal links are checked by the script below;
   external ones with curl (npmjs.com, basescan and the Solana explorer block curl and must
   be checked in a browser).

   ```sh
   python3 build.py
   grep -ho 'href="https\?://[^"]*"' index.html docs/*.html ecosystem/*.html | sed 's/href="//;s/"$//' | sort -u \
     | while read u; do printf '%s %s\n' "$(curl -s -o /dev/null -w '%{http_code}' -L "$u")" "$u"; done | grep -v '^200'
   ```
6. **One script.** `grep -rl '<script' --include='*.html' . | grep -v ^./src` must print
   only `./index.html`, whose one script is the copy-button handler at the end of the body:
   it touches the clipboard and nothing else, makes no request, and the page works without
   it. No page may reference another host for a stylesheet, font or image. The typing tape
   in the operators section is a CSS animation over real commands in workflow order;
   reduced motion holds its first line.

## Publishing

Upload every file that `manifest.template.json` lists through the store app behind the live
node, paid by the KiB with a voucher on an x402 channel. Fill each file's transaction id
into the manifest, upload the manifest, and point the ArNS record `toon` at the manifest's
transaction id. The manifest serves `index.html` at the root and every other path beneath
it, so `toon.ar.io/docs/run-a-node.html` resolves. The first paid writes are documented at
[boughtviatoonnode.ar.io](https://boughtviatoonnode.ar.io/).
