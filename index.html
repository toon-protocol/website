How a request travels

One packet, paid hop by hop.

Whoever pays sends one packet. Each connector on the way keeps its hop fee and passes the rest on. The last connector hands your app a plain HTTP request.

Six commands

From install to a paid app.

    On devnet the faucet sends test tokens, not ETH. On mainnet you send USDC to the printed address.

  4. 04

    Start it

    toon up writes a systemd --user unit, so the node outlives this terminal. toon status shows what is running and at which address.

    toon 0.2.0
    toon up toon status
  5. 05

    Join the network

    Until now the node reaches nobody. toon join peers your connector toward the network's hub and opens the channel that pays for the hop. From here it can pay anything on the network. The faucet sends no ETH: depositing into a channel, which joining a network does, costs gas, so send a little Base Sepolia ETH from a public faucet to the address toon wallet show lists. About 0.001 ETH is enough; Money has the details.

    toon 0.2.0 · devneta deposit of faucet tokens, plus Base Sepolia ETH for gas
    toon join devnet --deposit 1000000 --yes
  6. 06

    Put your app behind it

    Any HTTP service in a container image, at the price you choose. From then on every request that reaches it has been paid for.

    toon 0.2.0the price is in units of the token you settle in
    toon add echo --to relay --image echo-app --price 2 --yes toon route list

What your app sees

It never handles a payment.

The connector sits in front of your app. It refuses an unpaid request and says the price. Once the request is paid, it passes your app plain HTTP. Your app needs no SDK, no wallet and no billing code.

You set the price. There is no protocol fee: the only fees on a route are the hop fees that each connector chooses to charge.

There is no company you sign up with; anyone can run a connector. TOON builds on Interledger, the open protocol that routes value in packets.

Where it is reachable

Reachable with no open port

A new TOON app is reachable as a hidden service, at an .anyone address, with no open port and no public address. A hidden service is reached through the Anyone network, so it hides where your app is, though not who it pays: payments are on a public chain.

Run it from an agent

The same commands, as JSON.

Every toon command is non-interactive and accepts --json, and prints one JSON document. Every command that pays states its amount and needs --yes. An agent drives the same surface you do.

To pay one

One channel, then paid requests

Reads are free. Writes are paid. The client opens one channel toward the node it peers with, and every signed request after that reaches any app on the network, hop by hop, each hop keeping its fee. A refusal comes back as a value, not an exception.

ILP routes, x402 settles. Pay a node →

const client = await ToonClient.create({ connector, mnemonic, channelStore });

await client.channel.open({ deposit: 100_000n });     // once: 0.10 USDC

const answer = await client.send({ body: 'hello' });  // every request after
answer.fulfilled ? answer.text() : answer.code        // a refusal is a value
