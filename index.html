TOON Protocol · Value, routed

Put a price on any HTTP app.

Get paid per request, in USDC, with no protocol fee and no change to your app. One command installs toon. Three more give you a running node.

curl -fsSL https://raw.githubusercontent.com/toon-protocol/toon_cli/main/install.sh | sh

LinuxMIT licensedNo protocol feeSettles on Base and SolanaNo SDK in your app

NewYour first agent node, with toon →
$0.001one request, as the live node charges it
0 gasper request. A voucher is a signature
1 txsettles thousands of requests
0%protocol fee, no percentage cut

What you do

Four commands. A node that gets paid.

toon runs the node for you: a wallet, a relay, and a connector in front of any app you add. The first one is on the devnet and costs nothing.

  1. 01

    Install

    One line puts the release binary on Linux, x86_64 or aarch64. No Rust toolchain, no account.

    The shell
    curl -fsSL https://raw.githubusercontent.com/toon-protocol/toon_cli/main/install.sh | sh
  2. 02

    Create and fund it

    init makes the wallet and a relay reachable as a hidden service; the mnemonic is shown once. The faucet funds it with test tokens.

    Devnetfree
    toon init --accept-anyone-terms toon wallet fund
  3. 03

    Start it

    up writes a systemd --user unit, so the node outlives this terminal. status shows what is running and at which address.

    What status printed
    toon up toon status Supervisor: running. TOON app relay (ILP address g.toon.fb0e007c71750599): connector running on 127.0.0.1:25599.
  4. 04

    Put your app behind it

    Any HTTP service in a container image, at the price you choose. From then on every request that reaches it has been paid for.

    Your app, pricedin units of the token you settle in
    toon add echo --to relay --image echo-app --price 2 --yes toon route list
  5. 05

    Or let an agent run it →

    Every command takes --json, and every command that pays states its amount and needs --yes. An agent drives the same surface you do. spaceturtle is one that does.

    What an agent types--json on every command
    $ toon init --accept-anyone-terms toon wallet fund toon up toon status --json toon add echo --to relay --image echo-app --price 2 --yes toon route list --json toon event publish --kind 1 --content "hello" --json

To pay one

Paying is one install

The client asks a node what it charges, opens the channel once, and signs a voucher on every request after that. A refusal comes back as a value, not an exception. Pay a node →

TypeScriptnpm install @toon-protocol/client
const client = await ToonClient.create({ connector, mnemonic, channelStore });

await client.channel.open({ deposit: 100_000n });     // once: 0.10 USDC

const answer = await client.send({ body: 'hello' });  // every request after
answer.fulfilled ? answer.text() : answer.code        // a refusal is a value

How it holds

A paid reverse proxy. It terminates payment the way nginx terminates TLS.

An unpaid request is refused with the exact price. A paid one reaches your app as plain HTTP. The vouchers settle in batches on a chain. Your app never sees a payment.

On the wirex402 v2 over HTTP
# without a voucher
POST /ilp
402 Payment Required        amount 1000 · USDC on Base

# with one
POST /ilp + voucher         a signature, no gas
200                         your app's answer, sealed
Wire
x402 v2 over HTTP. Protocol and specs
Settlement
x402 batch-settlement channels. USDC on Base and Solana mainnet; devnets for free. Channels
Routing
Interledger. Routes chain across nodes with the payload sealed; each hop keeps its own fee. Where TOON sits
Reachability
Clearnet, or a .anyone hidden service with no domain and no open port. Hidden services
Contracts
None of TOON's own. x402's x402BatchSettlement on EVM, the Solana Foundation's payment-channels on Solana.
Software
MIT licensed. No protocol fee, no plan, no tier, no payout schedule. Apps, clients and rails

What it costs

You set the price. You keep the price.

A route charges a flat amount per request, plus an optional rate per KiB, in the token you settle in. Prices count the token's smallest unit: in USDC, 1,000 units is a tenth of a cent. Four apps are priced on the live node today.
