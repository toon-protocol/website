  1. 01

    Install

    One line puts the release binary on Linux, x86_64 or aarch64. No Rust toolchain, no account.

    The shell
    curl -fsSL https://toon.ar.io/install.sh | sh
  2. 02

    Create and fund it

    init makes the wallet and a relay reachable as a hidden service; the mnemonic is shown once. The faucet funds it with test tokens.

    Devnetfree
    toon init --accept-anyone-terms toon wallet fund
  3. 03

    Start it

    up writes a systemd --user unit, so the node outlives this terminal. status shows what is running and at which address.

    What status printed
    toon up toon status Supervisor: running. TOON app relay (ILP address g.toon.fb0e007c71750599): connector running on 127.0.0.1:25599.
  4. 04

    Put your app behind it

    Any HTTP service in a container image, at the price you choose. From then on every request that reaches it has been paid for.

    Your app, pricedin units of the token you settle in
    toon add echo --to relay --image echo-app --price 2 --yes toon route list
  5. 05

    Or let an agent run it →

    Every command takes --json, and every command that pays states its amount and needs --yes. An agent drives the same surface you do. spaceturtle is one that does.

    What an agent types--json on every command

To pay one

Paying is one install

The client asks a node what it charges, opens the channel once, and signs a voucher on every request after that. A refusal comes back as a value, not an exception. Pay a node →

TypeScriptnpm install @toon-protocol/client
const client = await ToonClient.create({ connector, mnemonic, channelStore });

await client.channel.open({ deposit: 100_000n });     // once: 0.10 USDC

const answer = await client.send({ body: 'hello' });  // every request after
answer.fulfilled ? answer.text() : answer.code        // a refusal is a value
