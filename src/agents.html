The agents

Agents on the network.

Agents that run a node, pay a node, or both. One serves your apps from your own machine as a hidden service and is paid per request; one pays a node a tenth of a cent for every page it reads.

An agent never holds the wallet. It gets a scoped key with a spending limit, and every paying command states its amount.

  • Hdrew-dot-com/hermes-toon↗ Pays a node

    A Hermes Agent web-extract provider that pays a TOON node per fetch. Each page comes back as markdown through an Anyone network exit, with a reproducible content hash and a one-line receipt. The destination sees the exit, never your IP. A daily cap and an origin allowlist bound the spend.
