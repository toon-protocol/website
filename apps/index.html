The apps

Built behind a node.

Open-source services that run behind a TOON node and are paid per request. None of them contains payment code; the node in front does the charging. Run any of them with toon add, or put your own behind a node and get listed.

Four are priced on the live mainnet node today. Prices are what it answers at GET /ilp, read on 2026-10-03.

  • toon-protocol/relay↗ Priced live

    A Nostr relay you get paid to write to. Reads are free and speak plain NIP-01, so any Nostr client can use it; writes arrive through the node, already paid. Every agent node carries one.

    ★0Rustrust-2026.10.03.4
    write a message $0.001devnet g.toon.relay
  • toon-protocol/store↗ Priced live

    A paid Arweave blob store that uploads through AR.IO's Turbo and returns the transaction id. Also brokers ArNS name purchases. This site was stored through it.

    ★0TypeScript
    store a file $0.001 + $0.00003 / KiBdevnet g.toon.store
  • toon-protocol/anytoon↗ Priced live

    The Anyone Protocol credentials issuer behind a node, reached only at a .anyone hidden-service address. A buyer pays over ILP and receives blind-signed credentials; the issuer runs as its published image, unmodified.

    ★1TypeScript
    fetch a URL anonymously $0.001ANYONE on Ethereum, or USDC on Base
  • toon-protocol/gas-station↗ Priced live

    Pays other people's gas. A peer holding no SOL gets a Solana transaction landed; a peer holding no ETH gets an EVM call mined. They pay in whatever they do hold.

    ★0TypeScriptMIT
    a Solana fee paid for you $0.012devnet g.toon.gas
  • toon-protocol/swap↗ Source

    Swap tokens across chains through a relay, with no server in between. A maker publishes an order; a taker streams it small fills; each side verifies the other's signed claim.

    ★0TypeScriptv3.0.3
    EVM, Solana, Mina@toon-protocol/swap
  • toon-protocol/provider↗ Source

    A compute provider that sells leases on OCI workloads over TOON payment channels, with a gateway that fronts a workload at a stable hostname and follows it across hosts.

  • toon-protocol/fractal↗ Research

# publish

Want your app listed?

Any HTTP service in a container image. Listen on a port, answer a request, and let the node in front of it take the payment. One toon add puts it behind your node at the price you choose; the store's repository is the worked example. Then open a pull request on this site.
