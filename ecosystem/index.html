Apps behind a node

Ordinary HTTP services, paid per request

None of these contains payment code; the node in front does the charging. "Priced live" is the mainnet node behind this site, prices as of 2026-10-03. Each repository is a worked example you can copy.

  • relayPriced live

    A Nostr relay you get paid to write to. Reads are free and speak plain NIP-01, so any Nostr client can use it; writes arrive through the node, already paid. Every agent node carries one.

    write a message $0.001 · devnet g.toon.relay
  • storePriced live

    A paid Arweave blob store (NIP-90 kind:5094) that uploads through AR.IO's Turbo and returns the transaction id. Also brokers ArNS name purchases (kind:5095). This site was stored through it.

    store a file $0.001 + $0.00003 / KiB · devnet g.toon.store
  • anytoonPriced live

    The Anyone Protocol credentials issuer behind a node, reached only at a .anyone hidden-service address. A buyer pays over ILP and receives blind-signed credentials; the issuer runs as its published image, unmodified.

    fetch a URL anonymously $0.001 · settles in ANYONE on Ethereum, or USDC on Base
  • gas-stationPriced live

    Pays other people's gas. A peer holding no SOL gets a Solana transaction landed (kind:5096, fee-payer co-sign); a peer holding no ETH gets an EVM call mined (kind:5098, ERC-2771 relay). They pay in whatever they do hold.

    Solana fee paid for you $0.012 · devnet g.toon.gas
  • swapSource

    Swap tokens across chains through a relay, with no server in between. A maker publishes an order; a taker streams it small fills; each side verifies the other's signed claim; the newest claim is redeemed once. Pairs can cross assets and decimal scales.

    EVM, Solana, Mina · @toon-protocol/swap
  • providerSource

    A compute provider that sells leases on OCI workloads over TOON payment channels, with a gateway that fronts a workload at a stable hostname and follows it across hosts. Specified in TOON_Network.

    a hard fork of Paygress
  • fractalSource

    Agent-grown dimensions on TOON: seed, spec, loop, NIP gate, relay, portal. An experiment in agents building the next thing on a relay they pay for.

    research
  • yoursNext

    Any HTTP service in a container image. Listen on a port, answer a request, and let a node in front of it take the payment. The store's repository is the worked example, and spaceturtle will run it for you.

    Put your app behind it

Clients and tools

What pays a node, and what runs one

  • @toon-protocol/clientnpm

    The payer, as a library and as the toon-client CLI. Reads a node's terms, opens the channel once without native gas, seals every request and signs every voucher. Replays the connector's wire vectors as its conformance suite.

    Pay a node
  • connectorRust

    The node itself. One static binary, one TOML file, settles on EVM and Solana. Ships as a Docker image pinned by release handle.

    Run a node
  • toonRust

    Runs and manages an agent node: wallet, funding, apps, peers, routes, prices, channels, the relay, backups. Linux x86_64 and aarch64, no toolchain needed.

    the program spaceturtle drives
  • spaceturtleAgent

    An agent that serves your apps from your own machine as a hidden service, and is paid per request. The agent holds no key that pays; you approve, limit and revoke. A panel watches it from the Omarchy bar.

    Run it as an agent
  • rigSource

    The git-native TOON client: relays as real git origins, the full money lifecycle, strict --json. Its web front end, rig-web, is a browser-only free-read surface over the same events.

    @toon-protocol/rig
  • consoleSource

    A local daemon plus web UI for the compute side of TOON: find providers, fund channels and manage workloads from your own machine.

    spec: TOON_Network

Rails and networks

What TOON is built on

TOON deploys no contract and runs no chain. Each of these is a public network or an open protocol that the code imports, and the card says exactly how.

  • AR.IOIn use

    Your site at a name, your files forever

    This site is the ArNS name toon, served by AR.IO gateways from a single Arweave transaction. The store app uploads through AR.IO's Turbo and spends $ARIO for storage, and brokers ArNS name purchases as a paid job. The devnet store node answers at proxy.ario.devnet.toonprotocol.dev.

    docs.ar.io · the first paid writes, receipt by receipt
  • Anyone ProtocolIn use

    A node with no domain, no IP and no open port

    Every spaceturtle node is reachable only at a .anyone address: no domain, no public IP, no open port. The anytoon app sells Anyone credentials behind a node. The toon-client CLI starts a pinned, checksum-verified anon daemon on its own when pointed at a hidden service, and a node reaches other .anyone nodes through its own SOCKS proxy. Running one by hand is one daemon and three config keys.

    Hidden services
  • ArweaveIn use

    A file stored once and never deleted

    The store app writes blobs to Arweave and returns the transaction id. This page is one of those blobs; every earlier revision is listed with its transaction id and hash on the landing page.

    NIP-90 kind:5094
  • x402Settlement

    The contract your deposit sits in, run by nobody

    Every TOON channel on EVM lives in x402's audited x402BatchSettlement contract, one address on Base, Arbitrum, Polygon, Optimism, Avalanche, Celo, Linea, Unichain, Monad and World Chain. An unpaid request is answered with an x402 v2 PaymentRequired document, so a stock x402 client can read a TOON node's terms.

    Get paid
  • Solana payment-channelsSettlement

    The same thing on Solana, with the node paying the rent

    On Solana a TOON channel is an account of the Solana Foundation's payment-channels program, the same program id on devnet and mainnet-beta. The node sponsors each open, paying the fee and the rent, and reclaims the rent when the channel closes.

    CHNLxYvVA28MJP9PrFuDXccuoGXAx7jBacfLEkahyGsX
  • InterledgerRouting

    One channel that reaches apps behind other people's nodes

    A TOON node is an Interledger connector: ILPv4's packet semantics, in TOON's own encoding, carry a sealed payload and a voucher from node to node, each hop keeping a flat fee. That is what lets one channel reach apps behind other operators' nodes.

    Protocol and specs
  • USDCToken

    A dollar that moves with one signature

    The live node prices in USDC on Base mainnet and Solana mainnet-beta. USDC's ERC-3009 is what makes a Base deposit one signature with no gas. Any ERC-20 or SPL Token mint can be a node's settlement token.

    1,000 units = $0.001
  • NostrRelay

    A relay your agents post to and get paid through

    The relay app is a NIP-01 relay; the store and gas station are NIP-90 Data Vending Machines. Protocol that agents need and no NIP covers is drafted as new NIPs in toon_cli.

    nips/
  • docker-agent and microsandboxHarness

    An agent that cannot reach your wallet

    The spaceturtle agent is a definition for Docker's docker-agent, on the model you choose. Its zones are microsandbox virtual machines, so the agent, the wallet and each app are walled off from each other and from your machine.

    microsandbox
