Proof

The landing page is not on a web server: every revision, its Arweave transaction and the receipts of the write that bought it.

It is one HTML file on Arweave, and the write that put it there was bought through the node priced on the ecosystem page: two paid hops, each paid with a voucher on an x402 channel on Solana mainnet. Each revision embeds the receipts of the ones before it, and every hash checks against a public chain. The node's first paid writes are at boughtviatoonnode.ar.io.
