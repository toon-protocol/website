Overview

What a TOON node is, the two roles, and which path to take.

A TOON node is a paid reverse proxy. You put it in front of an ordinary HTTP app, you set a price per route, and it collects that price from whoever calls, per request, in a stablecoin, without your app knowing payment exists. It terminates payments the way nginx terminates TLS.

Underneath, the node is an Interledger (ILP) connector: value arrives wrapped in a packet format your app never speaks, which is why the node's one endpoint is called /ilp, and at the last hop the node unwraps it, checks it was paid for, and hands your app a plain HTTP request. Every payment is a signed voucher, an IOU against a deposit the caller locked on chain once, on an x402 batch-settlement channel. So a request costs a signature, not a transaction, and one onchain transaction settles thousands of requests. You do not need to know anything about Interledger or x402 to run one.

Two roles, and nothing else

  • An app is an ordinary HTTP service behind a route's handler_url. It receives an ordinary HTTP request, holds no key on your behalf, and never sees a payment.
  • A connector sits in front of it. It opens the sealed payload, makes exactly that HTTP request of your app, and seals the app's complete response back.

The node refuses to let the app decide anything about a payment. "The app answered" and "the packet was paid for" stay separable, so an app that knows nothing about payment cannot leak, forge or withhold one.

Pick your path

  • I have an app to charge for Run a node in front of it. One Docker image, four lines of TOML, a settlement block. Then get paid on Base or Solana.
  • I want to pay for requests Install the client, make a wallet, open one channel, and buy a request. The first one is on devnet and costs nothing.
  • I want no domain, no certificate, no open port Run the node as a hidden service at a .anyone address: one daemon beside it, three config keys, done by hand.
  • I want an agent to run it spaceturtle runs a node from your own machine as a hidden service, with the agent kept away from the money.
  • I run a node and want traffic Peer with another node from its URL, carry its packets one hop further, and keep a fee.

What a paid request looks like

An unpaid request to a priced route is refused with the price. The refusal is a valid x402 v2 PaymentRequired document, so a caller never guesses what something costs.

On the wirex402 v2
# an unpaid request to a priced route
POST /ilp                  no voucher attached
402 Payment Required
{ "x402Version": 2,
  "accepts": [{ "scheme":  "batch-settlement",
               "network": "eip155:8453",
               "amount":  "1000",
               "payTo":   "0x…" }] }

# the same request, with a signed voucher
POST /ilp                  voucher: 1,000 units
200                        your app's answer, sealed

The caller opens a channel once, with a deposit, and then attaches a voucher to every request. A voucher states the channel's cumulative total; the node accepts it only if it advances the last one by at least the route's price. Losing a voucher costs nothing and replaying one buys nothing. Concepts defines each of those words.

What it costs

You set the price, in the smallest unit of the token you settle in, the way a card terminal counts cents. With USDC, price = 1000 is 0.001 USDC, a tenth of a cent. There is no protocol fee: what a caller pays lands in your channel, minus nothing. Gas is paid once per batch when the node lands vouchers on chain, never per request. Who pays gas, and why has the full table.

Where things live

RepositoryWhat it is
connectorThe node: one Rust binary, one TOML file. Its docs/ hold the specs, the ADRs and the wire vectors that every other repository replays.
toon-client@toon-protocol/client, the payer, as a library and as the toon-client CLI.
toon_clitoon, the program that runs and manages an agent node: wallet, apps, peers, routes, prices, channels and the relay.
spaceturtleThe agent and the harness that run an agent node from your own machine.
relay, store, gas-station, anytoonApps that run behind a node today, each a worked example of the app side. The ecosystem page lists them all.
